## در این فصل یاد می‌گیرید

- معادل فارسی درستِ همه اصطلاح‌های فنی این دوره آموزشی را
- توضیح یک‌خطی هر اصطلاح را برای مرور سریع
- این واژه‌نامه را به‌عنوان مرجع حین خواندن فصل‌های دیگر استفاده کنید

**راهنمای استفاده:** اصطلاح‌ها به پنج گروه موضوعی دسته‌بندی شده‌اند. هرجا در فصل‌های دیگر به واژه‌ای برخوردید که یادتان رفته، اینجا مرورش کنید. معادل فارسی پیشنهادی ما در ستون دوم آمده — در گفتگو و مستندات فارسی می‌توانید از آن استفاده کنید، اما در دستورها و تنظیمات همیشه باید همان انگلیسی را بنویسید.

## ۱. شبکه خصوصی و تونل‌گذاری

| اصطلاح انگلیسی | معادل فارسی | توضیح یک‌خطی |
|---|---|---|
| VPN | شبکه خصوصی مجازی | شبکه‌ای امن روی اینترنت عمومی که گویی همه اعضایش در یک ساختمان‌اند |
| WireGuard | وایرگارد | پروتکل مدرن و سبک تونل‌گذاری (رمزنگاری مسیر) که پایه Tailscale است |
| Tailscale | تیل‌اسکیل | نرم‌افزار کلاینت/سرور ساخت شبکه‌های مش (شبکه‌ی بافته‌ای) بر پایه WireGuard |
| Headscale | هداسکیل | نسخه متن‌باز و خودمیزبانِ «سرور هماهنگی» Tailscale — قلب این پروژه |
| Tailnet | تیل‌نت (شبکه اختصاصی) | نام شبکه خصوصی کامل شما؛ مجموعه همه دستگاه‌های عضوشده به یک سرور |
| Coordination Server | سرور هماهنگی | سروری که معرفی دستگاه‌ها به هم و توزیع کلیدها را انجام می‌دهد (اینجا: Headscale) |
| Control Plane | سطح کنترل | بخشِ «مدیریت و هماهنگی» شبکه — چه کسی کجاست و چه اجازه‌ای دارد |
| Data Plane | سطح داده | مسیر واقعیِ رفت‌وآمد داده‌ها بین دستگاه‌ها (معمولاً مستقیم و بدون عبور از سرور) |
| Peer-to-Peer | همتا به همتا | ارتباط مستقیم دو دستگاه بدون واسطه — روش ترجیحی انتقال داده در این معماری |
| Relay | رله | واسطه‌ای که وقتی اتصال مستقیم ممکن نیست، داده را از خودش عبور می‌دهد |
| DERP | رله DERP | رله استاندارد Tailscale برای مواقعی که اتصال همتا به همتا برقرار نمی‌شود |
| STUN | اِس‌تی‌اِن (کمکِ پشت NAT) | خدماتی که به دستگاه می‌گوید از دید اینترنت، IP و پورتش چیست |
| NAT | ترجمه آدرس شبکه | مکانیزمی که در روترها یک IP عمومی را بین چند دستگاه داخلی تقسیم می‌کند |
| CGNAT | ان‌ای‌تی در سطح اپراتور | وقتی اپراتور اینترنت، همان کار NAT را برای مشتریانش انجام می‌دهد — دشوارکننده اتصال مستقیم |
| 100.64.0.0/10 | رنج IP اختصاصی تونل | بازه آدرس‌هایی که Tailscale به دستگاه‌های شبکه اختصاص می‌دهد (مثل 100.64.0.2) |
| Handshake | دست‌دادن (هم‌دستی) | چند بسته اولیه بین دو طرف برای توافق روی کلید رمزنگاری |
| Keepalive | بسته پایدارکننده | بسته‌های کوچک دوره‌ای که اتصال NAT را از حافظه روتر دور نگه می‌دارد |
| Tunnel | تونل | مسیر رمزنگاری‌شده و منطقی بین دو دستگاه روی اینترنت عمومی |
| Captive Portal | درگاه اجباری ورود | صفحه‌ای که در وای‌فای هتل/فرودگاه قبل از اینترنت واقعی نشان داده می‌شود |

## ۲. آدرس‌ها، پروتکل‌ها و مسیریابی

| اصطلاح انگلیسی | معادل فارسی | توضیح یک‌خطی |
|---|---|---|
| IPv4 | نسخه ۴ پروتکل اینترنت | آدرس‌های عددی رایج مثل 192.168.1.10 |
| IPv6 | نسخه ۶ پروتکل اینترنت | نسل جدید آدرس‌ها با فرمت طولانی‌تر مثل fd7a:115c:… |
| IP Address | آدرس IP | شماره شناسنامه یک دستگاه در شبکه |
| Subnet Mask | نقاب زیرشبکه | عددی که مشخص می‌کند کدام بخش IP «محله» است و کدام بخش «پلاک» |
| CIDR | نشانه‌گذاری بازه شبکه | روش فشرده نوشتن بازه آدرس‌ها، مثل 192.168.1.0/24 (یعنی ۲۵۶ آدرس) |
| Port | درگاه (پورت) | شماره‌ای که مشخص می‌کند بسته به کدام برنامه روی دستگاه برسد، مثل 443 |
| TCP | تی‌سی‌پی | پروتکل قابل‌اتکا با تأیید رسیدن بسته‌ها (وب، SSH، API) |
| UDP | یو‌دی‌پی | پروتکل سریع بدون تأییدِ تک‌تک بسته‌ها (خود WireGuard و پورت 3478) |
| MTU | بیشینه حجم بسته | بزرگ‌ترین حجم یک بسته قابل ارسال؛ بزرگ‌تر از حد = تکه‌تکه‌شدن یا خطا |
| DNS | سرویس نام دامنه | دفترچه‌ی ترجمه نام‌ها (مثل example.com) به IP عددی |
| A Record | رکورد A | ثبتِ DNS که می‌گوید یک نام، به کدام IPv4 اشاره می‌کند |
| AAAA Record | رکورد AAAA | همان کار رکورد A اما برای آدرس‌های IPv6 |
| MagicDNS | دی‌ان‌اس جادویی | قابلیت صداکردن دستگاه‌ها با نام کوتاه (مثل laptop-reza) به‌جای IP تونل |
| Split DNS | دی‌ان‌اس تفکیک‌شده | تقسیم کار DNS: نام‌های داخلی به سرور داخلی، بقیه به DNS عمومی |
| Routing | مسیریابی | علم تصمیم‌گیری اینکه هر بسته از کدام مسیر به مقصد برسد |
| Route | مسیر | قاعده‌ای که یک بازه آدرس را به یک مسیر خاص می‌فرستد |
| Subnet Router | ساب‌نت‌روتر (مسیریاب زیرشبکه) | دستگاه عضوِ تونل که کل شبکه دفتر را به تونل وصل می‌کند (فصل ششم) |
| Exit Node | گره خروجی | دستگاهی که کل اینترنت شما از آن عبور می‌کند (فصل هفتم) |
| IP Forwarding | پیش‌رانش آدرس‌ها | قابلیت سیستم‌عامل برای عبوردادن بسته‌ها از یک کارت شبکه به دیگری — لازم برای ساب‌نت‌روتر |
| Port Forwarding | پیش‌رانش درگاه | بازکردن پورتی از روتر به داخل خانه/دفتر — روشی که در این پروژه عمداً استفاده نمی‌کنیم |

## ۳. رمزنگاری، وب و گواهی‌ها

| اصطلاح انگلیسی | معادل فارسی | توضیح یک‌خطی |
|---|---|---|
| TLS | امنیت لایه ترابرد | پروتکل رمزنگاری استاندارد ارتباطات اینترنتی |
| HTTPS | اچ‌تی‌تی‌پی امن | وب با رمزنگاری TLS — همان قفل کنار آدرس مرورگر |
| Certificate | گواهی دیجیتال | مدرک الکترونیکی که هویت یک دامنه را تأیید می‌کند |
| Let's Encrypt | لتس‌انکریپت | مرجع صدور رایگان گواهی‌های TLS — که Caddy خودکار از آن می‌گیرد |
| ACME | پروتکل دریافت خودکار گواهی | روش استاندارد سفارش/تمدید خودکار گواهی از مرجعی مثل Let's Encrypt |
| Reverse Proxy | پروکسی معکوس | دربانِ وب که درخواست‌های HTTPS را از سمت اینترنت به سرویس داخلی می‌رساند |
| Caddy | کندی | وب‌سرور/پروکسی معکوسِ این پروژه — مسئول HTTPS و گواهی‌ها |
| Encryption | رمزنگاری | تبدیل داده به شکلی که فقط طرفِ دارای کلید بتواند بخواند |

## ۴. سرور، سیستم‌عامل و ابزارها

| اصطلاح انگلیسی | معادل فارسی | توضیح یک‌خطی |
|---|---|---|
| VPS | سرور مجازی خصوصی | سروری که از شرکت می‌خرید و روی اینترنت عمومی می‌نشیند (میزبان Headscale شما) |
| Ubuntu | اوبونتو | توزیع محبوب لینوکس — سیستم‌عامل پیشنهادی این پروژه (نسخه ۲۲.۰۴ یا ۲۴.۰۴) |
| SSH | اِس‌اس‌اچ (پوسته امن) | راه اتصال رمزنگاری‌شده به خط فرمان سرور از راه دور — در ویندوز ۱۰/۱۱ هم از قبل نصب است |
| PowerShell | پاورشل | خط فرمان مدرن ویندوز — جای اجرای `ssh`، `tailscale` و `Get-FileHash` در ویندوز |
| CMD | سی‌ام‌دی (خط فرمان کلاسیک ویندوز) | محیط قدیمی‌تر Command Prompt ویندوز — همان دستورهای ssh/nslookup/tailscale در آن کار می‌کند |
| WSL | ساب‌سیستم ویندوز برای لینوکس | محیط لینوکسی داخل ویندوز؛ برای این پروژه لازم نیست — مدیریت سرور با ssh و کلاینت با اپ رسمی ویندوزی (فصل ۴، بخش ۴.۰) |
| Terminal | ترمینال | پنجرهٔ متنی اجرای دستور — در لینوکس/مک هم‌نام همین کلمه و در ویندوز معادلش PowerShell یا CMD است |
| sudo | سودو (اجرت مدیر) | پیشوند اجرای دستور با دسترسی مدیر (superuser) |
| systemd | سیستم‌دی | مدیر سرویس‌های لینوکس — سرویس‌ها را اجرا، متوقف و راه‌اندازی می‌کند |
| journalctl | ژورنال‌سی‌تی‌ال | دستور خواندن لاگ سرویس‌ها از دفترچه systemd |
| systemctl | سیستم‌کنترل | اجرا/توقف/وضعیت سرویس‌ها (`sudo systemctl status headscale`) |
| Firewall | دیوار آتش (فایروال) | نگهبانی که ترافیک ورودی/خروجی را بر اساس قواعد می‌گذارد یا می‌بندد |
| UFW | فایروال ساده اوبونتو | ابزار مدیریت فایروال در اوبونتو — که این پروژه پیکربندی‌اش می‌کند |
| SQLite | اس‌کیو‌لایت | پایگاه‌داده تک‌فایلی سبک — جایی که Headscale همه اطلاعات شبکه را نگه می‌دارد |
| FQDN | نام دامنه کامل | آدرس کامل با تمام بخش‌ها، مثل headscale.example.com |
| LAN | شبکه محلی | شبکه داخلی خانه/دفتر — مثل 192.168.1.0/24 دفتر شما |
| WAN | شبکه گسترده | سمت اینترنتی روتر شما؛ دنیای بیرون |
| Default Gateway | گیت‌وی پیش‌فرض | روتری که بسته‌های مقصدِ «خارج از محله» به آن سپرده می‌شوند |
| Static Route | مسیر ایستا | مسیری که دستی در روتر تعریف می‌شود (مثل مسیر 100.64.0.0/10 در فصل نهم) |
| gRPC | جی‌آرسی‌پی | پروتکل ارتباط مدیریتی Headscale — روی پورت داخلی 50443 |
| Exit Code | کد خروج | عددی که هر دستور در پایان برمی‌گرداند؛ 0 یعنی موفق |

## ۵. مفاهیم Headscale و مدیریت شبکه

| اصطلاح انگلیسی | معادل فارسی | توضیح یک‌خطی |
|---|---|---|
| Node | گره (دستگاه) | هر دستگاه ثبت‌شده در شبکه — گوشی، لپ‌تاپ یا سرور |
| User | کاربر | حساب روی سرور که گره‌ها زیرش ثبت می‌شوند (مثل کاربر هر همکار) |
| Preauth Key | کلید از پیش تأییدشده | «کد دعوت» که دستگاه جدید با آن بدون تعامل اضافه ثبت می‌شود |
| Auth ID | شناسه احراز هویت | کدی که در جریان ثبت تعاملی، سرور برای تأیید یک دستگاه تازه تولید می‌کند |
| Netmap | نقشه شبکه | فهرستی که هر گره درباره همسایه‌هایش (آدرس‌ها و کلیدها) از سرور می‌گیرد |
| Policy | سیاست | مجموعه قواعد سرور درباره اینکه چه کسی به چه کسی وصل شود |
| ACL | فهرست کنترل دسترسی | شکل سنتی سیاست‌ها: «چه کسی به چه چیزی اجازه دارد» |
| Grant | مجوز | واحد اجازه در سیاست‌های جدید Headscale (نسل بعد از ACL) |
| Backup | پشتیبان | بسته فشرده‌ای از پیکربندی، پایگاه‌داده و کلیدها برای روز مبادا |
| Restore | بازیابی | برگرداندن وضعیت سرور از روی فایل پشتیبان |
| Health Check | بررسی سلامت | آدرس `/health` و دستور `hsctl doctor` — نبض سرور شما |

## ۶. دستورهای خط فرمانی که در این دوره دیدید

این‌ها دستورهای سیستمی‌اند (نه مخصوص این پروژه) اما چون در فصل‌ها بارها به آن‌ها برخوردید، معادل و کارشان را یکجا آورده‌ایم:

| دستور | خوانده می‌شود | چه می‌کند؟ |
|---|---|---|
| `ping` | پینگ | آزمون کوچکِ «آیا این مقصد جواب می‌دهد؟» |
| `nslookup` | ان‌اس‌لوک‌آپ | پرسش از DNS: این نام به کدام IP می‌رسد؟ |
| `dig` | دیگ | نسخه حرفه‌ای‌تر همان پرسش DNS (nslookup برای ما کافی است) |
| `curl` | کرل | درخواست وب از خط فرمان — مثل تست `https://دامنه/health` |
| `scp` | اس‌سی‌پی | کپی امن فایل بین دو سرور از روی SSH (انتقال پشتیبان) |
| `chmod` | چمود | تغییر مجوز دسترسی فایل‌ها — مثل `chmod 600` برای پشتیبان‌ها |
| `df -h` | دی‌اف | میزان فضای اشغال‌شده و آزاد دیسک‌ها |
| `timedatectl` | تایم‌دیت‌کنترل | دیدن و تنظیم زمان، منطقه زمانی و همگام‌سازی NTP سرور |
| `ss -tulpn` | اس‌اس | فهرست پورت‌های باز و برنامه‌های شنونده روی سرور |

## چند نکته درباره نگارش

- در متن فارسی، اصطلاح انگلیسی را اولین بار با معادل فارسی بنویسید (مثل «کلید از پیش تأییدشده (Preauth Key)») و بعد از آن، هرکدام را که راحت‌ترید.
- در **دستورها، نام فایل‌ها و تنظیمات** همیشه انگلیسیِ دقیق را بنویسید؛ ترجمه فقط برای فهم است — مثلاً `hsctl doctor` را نمی‌شود «دکتر» صدا بزنید و انتظار کارش را داشته باشید!
- اگر اصطلاحی در این واژه‌نامه نبود، دو جای مطمئن دارید: `hsctl explain <topic>` روی خود سرور، و فصل مربوط به همان موضوع.

## چهار تفاوتی که معمولاً با هم اشتباه گرفته می‌شوند

| مقایسه | تفاوت یک‌خطی |
|---|---|
| Headscale در برابر Tailscale | Tailscale کل راه‌حل است؛ Headscale فقط جایگزینِ «سرور هماهنگی» آن برای میزبانی شخصی |
| اتصال مستقیم در برابر رله (DERP) | مستقیم = سریع و خصوصی؛ رله = پشتیبانِ وقتی که اتصال مستقیم ممکن نشد |
| Preauth Key در برابر Auth ID | کلید = ثبتِ بدون تعامل («کد دعوت»)؛ شناسه = تأیید تعاملی از سمت سرور |
| DNS در برابر MagicDNS | DNS نام‌های عمومی اینترنت را ترجمه می‌کند؛ MagicDNS نام دستگاه‌های شبکه خودتان را |

## خلاصه فصل

- بیش از ۶۰ اصطلاح ضروری این پروژه را در پنج گروه دیدید: تونل‌گذاری، آدرس‌ها و مسیریابی، رمزنگاری و وب، سرور و ابزار، و مفاهیم Headscale.
- معادل‌های فارسی پیشنهادی را برای گفتگو و مستندات داخلی به کار ببرید؛ در دستورها همیشه انگلیسی دقیق.
- این فصل مرجع سریع شماست — لازم نیست حفظش کنید، فقط بدانید کجاست.
