# Headscale Easy Manager — راهنمای نصب و استفادهٔ ویندوزی (فارسی)

> زبان‌ها: [English](README.md) · **فارسی**

> نسخهٔ پنل گرافیکی: مدیریت Headscale روی VPS شما، از داخل ویندوز، بدون هیچ دانش لینوکس.
> هر دکمهٔ این پنل به عملیات واقعی روی سرور (از طریق SSH و CLI رسمی Headscale) متصل است — هیچ دادهٔ ساختگی وجود ندارد.

---

## ۱. نصب

1. فایل `headscale-easy-manager-win-x64.zip` را از منبع رسمی دریافت کنید و صحت آن را با فایل `.sha256` کنارش بررسی کنید.
2. محتوا را در یک پوشهٔ دائمی باز کنید (مثلاً `C:\Tools\headscale-easy-manager`). **از پوشهٔ Downloads برای نصب دائمی استفاده نکنید.**
3. `install.bat` را دوبار کلیک کنید. این مرحله:
   - میان‌بر دسکتاپ و منوی استارت می‌سازد؛
   - پوشهٔ دادهٔ شما را در `%LOCALAPPDATA%\headscale-easy-manager` می‌سازد؛
   - به هیچ دسترسی مدیر (Administrator) نیاز ندارد.
4. با میان‌بر «Headscale Easy Manager» برنامه را اجرا کنید.

**پیش‌نیازها:** فقط ویندوز ۱۰/۱۱. نیازی به WSL، لینوکس، داکر، پایتون یا نصب دستی هیچ چیز نیست — زمان‌اجرای برنامه داخل بسته هست.

## ۲. اولین اجرا (جریان پیشنهادی)

1. برنامه بالا می‌آید و مرورگر `http://localhost:3000` را باز می‌کند (فقط روی همین سیستم — از اینترنت قابل‌دسترس نیست).
2. در سایت، بخش **پنل مدیریت** را باز کنید.
3. **سرورها → افزودن سرور**: آدرس VPS، پورت SSH (پیش‌فرض ۲۲)، نام کاربری، رمز یا کلید خصوصی، و روش sudo را وارد کنید.
4. **تست اتصال** را بزنید — برنامه واقعاً به سرور وصل می‌شود و **اثر انگشت کلید میزبان (SSH Host Key)** را نشان می‌دهد. آن را با خروجی `ssh-keygen -l -f /etc/ssh/ssh_host_ed25519_key.pub` روی سرور (یا اولین باری که خودتان با SSH وصل می‌شدید) مقایسه کنید و سپس «تأیید کلید میزبان» را بزنید.
   - اگر بعداً این اثر انگشت تغییر کند، برنامه اتصال را قطع می‌کند و به شما هشدار می‌دهد — این محافظت شما در برابر سرور جعلی است.
5. **نصب Headscale**: ویزارد ۴ مرحله‌ای — کشف محیط (سیستم‌عامل/رم/دیسک/پورت‌ها با علت واقعی هر مشکل)، تنظیمات (دامنه، MagicDNS، TLS با Caddy یا پروکسی خودتان)، پیش‌نمایش دقیق تغییرات، اجرای مرحله‌ای با گزارش زنده.
6. بعد از نصب، از **ثبت‌نام دستگاه** کلید اتصال بسازید و دستگاه‌هایتان را وصل کنید (راهنمای آماده برای ویندوز/اندروید/لینوکس/macOS در همان صفحه هست).

## ۳. کارهای روزمره

- **داشبورد**: وضعیت واقعی سرویس/نسخه/سلامت/شمار کاربران و دستگاه‌ها.
- **کاربران / دستگاه‌ها / کلیدها**: ایجاد، تغییر نام، حذف (با تأیید صریح)، انقضا — همه واقعی.
- **مسیرها (ساب‌نت‌روتر)** و **Exit Node**: با جداسازی سه‌مرحله‌ای (اعلام کلاینت → تأیید سرور → پذیرش کلاینت‌ها) — تا تأیید سرور واقعی انجام نشود، وضعیت «فعال» نمایش داده نمی‌شود.
- **سیاست دسترسی / پیکربندی**: ویرایشگر با اعتبارسنجی واقعی (خطای خط/موقعیت از خودِ سرور) + diff + پشتیبان خودکار قبل از هر تغییر.
- **پشتیبان و بازیابی / ارتقا**: با پشتیبان‌گیری خودکار قبل از هر عملیات مخرب.
- **ماتریس قابلیت‌ها**: وضعیت صادقانهٔ پوشش هر قابلیت CLI نسخهٔ هدف.

## ۴. عیب‌یابی

| نشانه | اقدام |
|---|---|
| «سرور اتصال SSH را رد کرد» | پورت SSH در فایروال VPS باز است؟ `sshd` روی سرور فعال است؟ |
| «احراز هویت SSH ناموفق بود» | رمز/کلید/نام کاربری پروفایل را ویرایش کنید. |
| «کلید میزبان تغییر کرده» | اگر سرور را بازسازی/جابه‌جا کرده‌اید، در همان کارت «بازنشانی اثر انگشت» را بزنید؛ وگرنه اتصال را جدی بگیرید. |
| ویزارد می‌گوید پورت ۸۰/۴۴۳ اشغال است | سرویس قبلی روی سرور آن پورت را گرفته — در پنل «کشف» علت دقیق (نام فرایند) را می‌بینید. |
| سرور بالا نیامد (start.bat) | `server.log` کنار برنامه را ببینید؛ معمولاً پورت ۳۰۰۰ اشغال است — برنامهٔ دیگری را ببندید. |
| «بررسی عمومی» کد ۲۰۰ نمی‌دهد | رکورد A دامنه را به IP عمومی سرور تنظیم کنید و چند لحظه بعد دوباره بررسی کنید (نمونهٔ خطای واقعی با کد واقعی نمایش داده می‌شود). |
| پنل باز نمی‌شود | مطمئن شوید فقط یک نمونه در حال اجراست (`stop.bat` سپس `start.bat`). |

## ۵. امنیت — چه چیزی کجا ذخیره می‌شود

- **رمز/کلید SSH پروفایل‌ها**: فقط در کامپیوتر خودتان، در `%LOCALAPPDATA%\headscale-easy-manager`، با رمزنگاری AES-256-GCM. اگر «ذخیرهٔ راز» را خاموش کنید، اصلاً ذخیره نمی‌شود.
- **کلیدهای خام (اتصال/API)**: فقط یک‌بار هنگام ساختن نمایش داده می‌شوند؛ هیچ‌جا ذخیره نمی‌شوند.
- پنل فقط روی `127.0.0.1` گوش می‌دهد؛ API آن در برابر درخواست‌های وب‌سایت‌های دیگر (Origin/DNS rebinding) محافظت شده است.
- هیچ عملیاتی روی VPS بدون تأیید صریح شما (و نمایش پیش‌نمایش تغییرات) انجام نمی‌شود.

## ۶. به‌روزرسانی / حذف

- **به‌روزرسانی خود برنامه**: بستهٔ جدید را باز کنید و `install.bat` همان پوشه را اجرا کنید — داده‌های شما (`%LOCALAPPDATA%`) دست‌نخورده می‌ماند.
- **ارتقای Headscale روی VPS**: از داخل پنل، بخش «ارتقا» (با پشتیبان خودکار).
- **حذف**: `uninstall.bat` — داده‌های شما حذف نمی‌شود؛ برای حذف کامل، پوشهٔ `%LOCALAPPDATA%\headscale-easy-manager` را دستی پاک کنید.

## ۷. صداقت در گزارش

این برنامه هیچ‌وقت موفقیت جعلی نشان نمی‌دهد:
- وضعیت «فعال» فقط بعد از تأیید واقعی همهٔ مراحل لازم است؛
- خطاها عیناً همان پیام واقعی سرور/CLI هستند؛
- در «ماتریس قابلیت‌ها» می‌بینید هر قابلیت در چه وضعیتی است (تست‌شده / نیازمند VPS واقعی / نیازمند دستگاه کلاینت / در نسخهٔ هدف موجود نیست).
