# Headscale Easy Manager — مدیر آسان هداسکیل

> زبان‌ها: [English](README.md) · **فارسی**

**برنامهٔ ویندوزی + رابط وب فارسی برای راه‌اندازی و مدیریت شبکهٔ خصوصی Headscale — با اتصال SSH واقعی به سرور شما، نصب‌کنندهٔ مرحله‌ای و پنل مدیریت کامل.**

این پروژه برای کسی ساخته شده که یک سرور (VPS اوبونتو) دارد و می‌خواهد بدون تسلط بر لینوکس، شبکهٔ خصوصی خودش را با [Headscale](https://headscale.net) (نسخهٔ مستقل و متن‌باز سرورِ کنترل Tailscale) راه بیندازد و روزمره مدیریت کند: نصب از صفر، ساخت کاربر و کلید اتصال، تأیید دستگاه‌ها و مسیرها، پشتیبان‌گیری و ارتقا — همه از یک رابط فارسی، با توضیح صادقانهٔ هر قدم و بدون هیچ دادهٔ نمایشیِ جعلی.

> نسخهٔ هدف: **Headscale v0.29.5** — همهٔ حقایق فنی در [`headscale-easy-manager/docs/FACTS.md`](headscale-easy-manager/docs/FACTS.md) قفل شده است. گزارش تغییرات: [`headscale-easy-manager/CHANGELOG.md`](headscale-easy-manager/CHANGELOG.md).

## این محصول چیست؟

| جزء | توضیح |
|---|---|
| **برنامهٔ ویندوزی** | یک فایل exe (Bun compile) که hem-agent و رابط کاربری را در خود دارد — بدون نصب وابستگی اضافه (ساخت: بخش «بستهٔ ویندوز» پایین) |
| **رابط وب فارسی** | کنسول کامل RTL: مرکز اتصال، داشبورد زنده، ویزارد نصب ۵ مرحله‌ای، کاربران/دستگاه‌ها/کلیدها/مسیرها/سیاست، پیکربندی، سرویس و لاگ، پشتیبان/ارتقا، کنسول امن و مرکز آموزش ۱۷ فصلی |
| **اتصال SSH واقعی** | همهٔ عملیات از طریق hem-agent با ssh2 روی سرور شما اجرا می‌شود — چیزی که می‌بینید خروجی واقعی سرور است، نه شبیه‌سازی |
| **نصب‌کنندهٔ مرحله‌ای** | همان نصب‌کنندهٔ پایتون ۱۷گامیِ مخزن `headscale-easy-manager` (با Dry-Run و رضایت صریح) از داخل رابط وب، با خروجی زنده |
| **پنل مدیریت کامل** | پشتیبان‌گیری/بازیابی با راستی‌آزمایی per-file، ارتقا با rollback واقعی بستهٔ قبلی، فایروال با snapshot و rollback |

## معماری (کوتاه)

```
ویندوز شما                                 سرور شما (VPS اوبونتو)
┌─────────────────────────┐               ┌───────────────────────────┐
│  hem-agent.exe          │   SSH (ssh2)  │  install.sh + hsctl      │
│  ├─ REST + socket.io    │ ════════════► │  ├─ headscale 0.29.5     │
│  ├─ TOFU اثرانگشت میزبان│  فقط پورت ۲۲  │  ├─ Caddy (TLS خودکار)   │
│  ├─ مخزن اسرار ویندوز   │               │  └─ UFW (با rollback)    │
│  └─ UI استاتیک embed    │               └───────────────────────────┘
└─────────────────────────┘
```

سه قطعهٔ اصلی:

1. **`mini-services/hem-agent/`** — سرویس agent (Bun/TypeScript): موتور SSH واقعی، مدیریت پروفایل و اثرانگشت میزبان (TOFU)، مخزن اسرار، allowlist کنسول، آداپتورهای CLI واقعی headscale، اجرای نصب با استریم زنده + REST و socket.io.
2. **`src/`** — رابط کاربری فارسی (Next.js 16، خروجی static export) که در مرورگر محلی باز می‌شود و با agent صحبت می‌کند.
3. **`headscale-easy-manager/`** — مخزن نصب‌کننده و CLI پایتون (`install.sh` + `hsctl`): منبع واحد حقیقتِ نصب؛ agent فقط همین مخزن را روی سرور آپلود و اجرا می‌کند.

## شروع سریع (توسعه)

پیش‌نیاز: [Bun](https://bun.sh) (نسخهٔ ۱ به بالا).

```bash
bun install            # نصب وابستگی‌ها
bun run docs:generate  # تولید محتوای مرکز آموزش از docs/fa (الزام قبل از dev/build)
bun run dev            # رابط وب روی http://localhost:3000

# agent (در ترمینال جدا):
cd mini-services/hem-agent
bun install
bun run dev            # سرویس روی 127.0.0.1:3005
```

بیشترِ کارها بدون سرور واقعی هم ممکن است: در مرکز اتصال، کارت «سرور آزمایشی» یک سرور SSH دموی داخلی را یک‌کلیکی پر می‌کند (مخصوص آزمایش جریان TOFU و عملیات مدیریتی روی headscale واقعیِ داخل sandbox).

## بستهٔ ویندوز (exe)

ساخت فایل exe تک‌فایلی ویندوزی (Bun compile + UI استاتیک embed) در [`mini-services/hem-agent/packaging/`](mini-services/hem-agent/packaging/) مستند شده است — اسکریپت ساخت، الزامات و مراحل امضا/انتشار.

## ساخت release

بستهٔ انتشار (تاربال + چک‌سام) با یک دستور ساخته و «خودآزمایی» می‌شود:

```bash
bash scripts/release.sh
```

این اسکریپت: محتوای آموزش را بازتولید می‌کند، `tsc --noEmit` و `lint` را به‌عنوان گیت الزامی اجرا می‌کند، بسته را فقط از allowlist گرد می‌آورد (مخزن پایتون از `git archive HEAD` — بدون `.git` و کش‌ها؛ بدون `.env`، دیتابیس توسعه، `node_modules` و لاگ‌ها)، سپس محتوای تاربال را خودش بررسی می‌کند و خروجی را در `download/` می‌نویسد:

```
download/headscale-easy-manager-v0.3.2-beta.5.tar.gz
download/headscale-easy-manager-v0.3.2-beta.5.tar.gz.sha256
```

## امنیت

- **اثرانگشت میزبان (TOFU):** اولین اتصال، اثرانگشت SHA256/MD5 کلید سرور را نشان می‌دهد و بدون تأیید صریح شما هیچ اتصالی برقرار نمی‌شود؛ اگر سرور بعداً کلید متفاوتی نشان دهد، اتصال با هشدار امنیتی (احتمال MITM) متوقف می‌شود و راه فراموشی، تأیید صریح می‌خواهد.
- **allowlist کنسول:** کنسول پیشرفته فقط دستورات محلیِ مجاز را با argv اعتبارسنجی‌شده اجرا می‌کند (بدون شل آزاد)؛ پیش‌نمایش، عین همان فرمانی است که اجرا می‌شود و دستور مسدود هرگز اجرا نمی‌شود.
- **ذخیرهٔ امن اسرار در ویندوز:** رمز سرور فقط با رضایت شما و از طریق PasswordVault ویندوز (Credential Manager) ذخیره می‌شود؛ به‌طور پیش‌فرض هیچ سری روی دیسک نوشته نمی‌شود و لاگ‌های حسابرسی هرگز رمز یا کلید کامل نمی‌بینند.
- **چک‌سام الزامی:** هیچ بستهٔ headscale بدون تطبیق SHA-256 رسمی دانلود یا نصب نمی‌شود.
- جزئیات کامل: [`headscale-easy-manager/SECURITY.md`](headscale-easy-manager/SECURITY.md) و ممیزی مستقل [`headscale-easy-manager/docs/AUDIT-2025-10.md`](headscale-easy-manager/docs/AUDIT-2025-10.md).
